# Ossa Latina

Справочник и тренажёр ударения в латинской остеологической номенклатуре — для студентов-медиков.

**Сайт:** https://martimorrr.github.io/ossa-latina/

## Что внутри

**266 терминов** по десяти разделам: от общих слов (`processus`, `tuberositas`, `incisura`) до костей запястья и свода стопы. Каждая карточка показывает три вещи:

- **просодическую строку** — слово по слогам со знаками долготы и краткости (`tu·ber·cŭ·lum`), ударный слог выделен;
- **транскрипцию** — `ту·бэ́р·ку·люм`, по правилам чтения русской медицинской традиции;
- **правило**, по которому ударение попало именно сюда: «уменьшительные суффиксы -ŭl-, -cŭl-, -bŭl- краткие → ударение уходит на третий слог от конца».

**Озвучка** — все термины произнесены с правильным ударением, один аудиофайл на весь словарь.

**Тренажёр** — четыре режима (поставить ударение, латынь → перевод, перевод → латынь, на слух) с интервальным повторением по коробкам Лейтнера. Прогресс хранится в браузере, у каждого свой.

**Правила** — три закона ударения, таблицы долгих и кратких суффиксов, чтение `c`, `s`, `ti`, `ae`, `ngu`, `ch/ph/rh/th` с примерами.

## Откуда взяты ударения

222 термина из 266 подчиняются механическим правилам (долгота по положению, дифтонги, суффиксы) — их можно проверить по написанию слова, не заглядывая в словарь. Остальные опираются на словарную долготу.

База сверена автоматически: 262 уникальных латинских слова сопоставлены с леммами Викисловаря (формы с макронами и классическое IPA). Из 102 слов, для которых нашлись словарные данные, совпало 101. По итогам сверки исправлены термины на `-oīdeus` (ударение на «i»: `masto-Ī-de-us`, а не на «e») и `os tríquetrum`.

Источники: [Wiktionary](https://en.wiktionary.org/wiki/pterygoideus), [The Latin Language and Bases of Medical Terminology (ОНМедУ)](https://repo.odmu.edu.ua/xmlui/bitstream/handle/123456789/1236/YeryomkinaLatinLanguage.pdf).

Кафедры расходятся в спорных местах (например, `os coccýgis` против этимологического `cóccygis`) — сверяйтесь со своей методичкой.

## Файлы

| файл | что это |
|---|---|
| `index.html` | страница сайта, собирается скриптом — править не нужно |
| `src/app.html` | исходник страницы: разметка, стили, логика |
| `terms.js` | база терминов: слогоделение, ударение, транскрипция, перевод, правило |
| `audio.js` | тайминги озвучки: id термина → начало и длительность в аудиофайле |
| `audio/` | озвучка: отдельный файл на термин плюс `index.json` со списком |
| `ossa.mp4` | та же озвучка одним файлом — запасной вариант для сборок без папки `audio/` |
| `build.py` | собирает `index.html` из `src/app.html` |
| `tools/build_sprite.py` | генерирует озвучку и тайминги заново |
| `tools/split_clips.py` | режет озвучку на отдельные файлы |

### Как добавить термины

В `terms.js` формат записи такой:

```js
["tu·BER·cŭ·lum", "ту·БЭР·ку·люм", "бугорок", "ul", "basic"]
```

Слоги разделены `·`, слова — пробелом, **ПРОПИСНЫЕ** буквы помечают ударный слог, макрон (`ā`) означает долгий слог, бреве (`ŭ`) — краткий. Последние два поля — код правила из `RULES` и раздел из `SECTIONS`.

После правки базы нужно пересобрать озвучку (`tools/build_sprite.py`) и страницу (`build.py`).

## Озвучка

Синтезирована локально моделью [Silero v4](https://github.com/snakers4/silero-models) (голос `xenia`) по транскрипции с явно проставленным знаком ударения — поэтому ударный слог всегда на месте. Системные синтезаторы так не умеют: macOS Milena, например, игнорирует любые пометки ударения и на все семь способов их записать выдаёт побайтово одинаковый файл.
